# 建築士向け ToDo アプリ

フリーランス建築士が、案件ごとのタスク（現地調査の予約、図面チェックの期限、施主への連絡など）を
**「今日・今週・今週以降」に自動で振り分けて、いま何をすべきかを一目で把握できる**シンプルな ToDo アプリです。

**デモ**: https://architect-todo-app.vercel.app

## できること

- タイトルだけで素早くタスクを登録（締切日・優先度・カテゴリは任意）
- 締切日にもとづく「今日 / 今週 / 今週以降」の自動振り分け（期限切れは「今日」に表示）
- 検索と絞り込み、カテゴリ付け、月間カレンダー表示
- 完了済みタスクの一覧と、ワンタップでの完了取り消し
- スマホ片手操作を想定したレイアウト（PC 表示にも対応）

## 使い方

1. 画面右下の追加ボタンからタスクを登録します。
2. 完了したらチェックを入れると一覧から消え、「完了済み」画面に移ります。
3. 各タスクの「⋮」メニューから編集・削除ができます。

データはお使いのブラウザ内（`localStorage`）にだけ保存され、サーバーには送信されません。
ログインや複数人での共有はありません。

## 技術構成

HTML / CSS / JavaScript のみの静的サイトです（ビルド不要・フレームワークなし）。Vercel でホスティングしています。

## ローカルで動かす

`index.html` をブラウザで開くだけで動きます。

```bash
npx serve .
```
